# 橡子旅馆 · 大纲与伏笔台账（v2.0）

> 按 webnovel-writer `webnovel-plan` 方法论：章节节拍 + 伏笔台账（埋设→回收全链路）+
> 三线交织检查。大纲即法律——正文（js/stages/*.js）严格执行本档。

## 一、三线定义（strand-weave 适配）

- **Quest（解谜主线）**：每晚一个房间、一个谜题、一块记忆碎片，直到保管库。
- **Fire（感情线）**：记忆场景（CONFIG 个人内容）、收藏家纸条、无声服务暗线。
- **Constellation（世界观线）**：登记簿残页、广播、八音盒、走调的歌、隐藏日记。

每晚配比：Quest 主导，Fire 至少两拍（记忆+纸条），Constellation 至少一拍（残页/广播）。

## 三、章节节拍

### 序章（intro.js）
1. 冷开场四行（第四次入住）。
2. 邀请函：无预订、日期＝纪念日、寄信人「你最熟悉的陌生人」。
3. 八条守则逐条亮出；规则五当场改字（F2）；规则〇缺失。
4. 登记簿签名：三行模糊名字随她落笔亮起（F9）。
5. 钩子：没按过电梯，电梯自己到了——不给「我要查明真相」式总结。

### 第一晚 · 海之房（night1.js）
1. 电梯：无4层；按钮异象各写一条规则暗线（B4=F7，广播=F3，年份倒走=F10）。
2. 五扇门：门1镜子（F8）、门2温把手（F6）、门4字条、门5针线声（F1）；两次错→海员熊登场救场。
3. 行船捞回忆光（boatGame）。
4. **海浪骤停（F5）**→答题→记忆场景1。
5. 残页1（Constellation）＋纸条1（Fire）。
6. 钩子：徒步熊下楼，登山杖是湿的（F4）。

### 第二晚 · 山之房（night2.js）
1. 三盏灯谜题：谎灯说甜话、真灯认自己又远又慢；错一次→徒步熊登场。
2. 红雾吃路，攀登追逐（climbGame）→答题→记忆场景2。
3. 分身事件（F7规则七）：三种选择，各留一条线索，不解释。
4. 残页2（多一行新墨：她今晚回来取过了）。
5. 红色警报：回收程序倒计时（F14）＋走调的歌（F11）＋熄灯钩子。

### 第三晚 · 夜之房（night3.js）
1. 连体衣熊登场：全程压着「最后一句」的悬（F2）。
2. 手电筒找五句低语（flashlightGame）→辨假话（CONFIG.whispers）。
3. 八音盒调音（旅馆的心跳）→纸条：曲是它守的，词是他改的（F11）。
4. 答题→记忆场景3。
5. 残页3（背面她的笔迹：明年的我还会回来吗）→三页拼合（F9强化）。
6. 钩子（本作最狠）：天亮前熊说完「最后一句」——「你没有丢过任何东西。」
   守则说最后一句是假话。她带着这句「谎言」走向最终晚。

### 第四晚 · 保管库（night4.js）
1. 第五扇门自开（F1）：一瞥缝衣房；橡子落肩；走廊坍塌追逐（hallGame，广播礼貌倒计时）。
2. 橡子钥匙入锁（F7）→第四张纸条撕在「其实我——」（F13）→最终密码（F12）。
3. 保管库开：一墙四年；三张「前住客留言」→**前三位住客都是你**（F9）。
4. 终章节拍（逐条回收）：F1→F8→F3/F11→F4→F5→F6→分身→F14反转→**F2复原（最后一句是真话）**→F10→熊与橡子→F13（撕掉的下半句）。
5. 规则〇藏头（余生请多指教）→永久房卡→「现在，转身。」
6. 隐藏结局（4橡子）→入住报告→尾屏。
